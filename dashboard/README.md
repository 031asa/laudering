# 发现期数据分析看板

双击 `发现期数据分析看板.html`，无需服务器或联网。HTML 内嵌汇总数据，不依赖外部 JavaScript、字体或图表库。`dist/index.html` 为同内容本地预览入口。

仅分析 2022-09-01～09-07，共 14,935,508 笔交易、11,360 笔正例。可选择全部 28 个连续日期区间。正式日期划分配置保持不变。

包含付款/收款币种、支付方式、小时、跨行、跨币种、自转账的构成、正例率、Lift、Cramér’s V 和逐日变化；分币种金额对数直方图、分箱累计曲线、分位数和秩效应；账户参与/付款/收款次数和活跃天数；实体登记/活跃账户数、关联银行数与账户加权视角。

交易类别计数、金额直方图、账户和实体统计均为全量。金额分位数和效应使用全部正例及按来源序号稳定哈希抽取的约 1% 负例；正例分位数全量、负例分位数及KS/秩效应为估计。分析中金额转float，不修改银层精确金额。累计曲线按0.25对数宽度分箱近似。没有计算p值、AP或模型效果。

账户主键为银行＋账户；风险参与分组随窗口重新计算，自转账参与次数只计一次。实体主键为entity_id，默认每实体一次；账户加权视角明确单列。完整账户元数据仅用于匹配和登记规模，没有历史生效日期，不能声称这些元数据均为历史时点已知。

当前未计算独立交易对手数、多时间窗口行为或图模式。以上均为发现期描述，不能把账户参与标签解释成真实违法认定，不能把发现期差异称为内部验证结果。

生成入口（复用本机 Anaconda 的 numpy/pandas/pyarrow/scipy）：

```powershell
& 'C:\anaconda\python.exe' scripts/build_dashboard_data.py
& 'C:\anaconda\python.exe' scripts/render_dashboard.py
```

前一个入口只读取发现期七个交易目录及账户元数据，约4分钟；后一个入口校验28个区间的统计汇总一致性并生成HTML。汇总来源、数据清单哈希和方法记录于 `result/dashboard/data.json`。
