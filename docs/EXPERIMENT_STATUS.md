# 实验状态（2026-10-10）

项目使用 IBM AML HI-Medium 合成交易数据，采用严格历史时间因果的双方向两层 GINE 交易分类。lr_only 是 GNN 学习率配方名，不是逻辑回归。A 指 features_only。

## 固定范围

Train：2022-09-01 至 09-10，20,318,992 笔、17,794 正例。Validation：09-11 至 09-13，4,689,006 笔、6,420 正例。每次完整 Train 一个 epoch，固定图采样和批序，CUDA、lr=0.0003、width=64、dropout=0.1、AdamW weight_decay=0.0001、clip=5。

lr_only 输入 N63/R110，A 输入 N63/R169。三个新种子为 20261009、20261010、20261011，两配方配对；原开发种子 20260920 单独列为第四次。只改变初始化与训练随机性，不增加候选或训练轮数。树模型实验已取消。

## 已完成的 Validation 结果

| 种子 | 配方 | 最大 F1 | AP | 精确率至少 80% 时的召回 |
|---|---|---:|---:|---:|
| 20260920（原开发种子） | lr_only | 0.654258 | 0.613814 | 0.550312 |
| 20260920（原开发种子） | A | 0.653180 | 0.611120 | 0.550623 |
| 20261009 | lr_only | 0.644960 | 0.605651 | 0.538162 |
| 20261009 | A | 0.646075 | 0.610225 | 0.540187 |

第一对新种子已完成训练和完整 Validation；其余四次仍在进行。新种子上 A 的 F1 高 0.1115 个百分点，原种子上 A 低 0.1078 个百分点。目前不能认定哪种配方稳定胜出，也不能据此认定只有架构改进才可能提升。

## 最终 Test 约定

用户在 2026-10-10 授权一次最终测试：两配方各四个种子，共八个模型。Test 固定 09-14 至 09-16，6,883,233 笔、6,932 正例；09-17 之后的尾部继续封存。

每个模型固定使用自己在 Validation 选出的最大 F1 阈值及 P80 阈值，在 Test 上报告实际 precision/recall/F1、AP 和配对结果。Validation 的 P80 阈值不保证 Test 上仍达到 80% 精确率。不按 Test 选阈值、种子、配方或调整训练；不替换部署模型。已有模型先测，其余模型完成 Validation 后再测。Test 尚未产出结果。
